Install AMA

AMA runs on the Windows PC that has the optical drive. It installs for your user only, without admin rights, and opens Setup in your browser when it’s done.

What you need

ThingWhy
Windows 10 or 11AMA runs as a normal app on your account and starts when you sign in.
An optical driveA Blu-ray drive reads every Disc Type. UHD Discs need a drive that reads them.
MakeMKVFor DVDs and Blu-rays. You install it; AMA finds it.CDs don’t need it.
Plex Media ServerOn this PC or another one, as long as it can see your Library folders.
Space for scratchA Rip waits on this PC until it’s encoded. A UHD Disc can take up to 100 GB.

AMA downloads its other tools itself the first time it starts: ffmpeg and cyanrip, at versions it has been tested with.

Download

Get the installer from the latest release on GitHub. It’s one file, AMA-Setup-x.y.z.exe, where x.y.z is the version.

Download for WindowsLatest release on GitHub

Run the installer

Windows will warn you first

The installer isn’t code-signed yet, so SmartScreen shows “Windows protected your PC”. Choose More info, check the publisher line reads Unknown publisher and the file name is AMA-Setup-x.y.z.exe, then choose Run anyway.

  1. Open the file you downloaded.
  2. Leave Start AMA when I sign in ticked unless you want to start it yourself from the Start menu.
  3. Choose Install. The installer sets up a private copy of Python and AMA’s libraries inside the app folder, so nothing else on the PC changes.
  4. When it finishes, AMA starts and opens Setup in your browser at http://127.0.0.1.

Where AMA keeps its files

WhatWhere
Settings%LOCALAPPDATA%\AMA\ama.tomlChange them on the Settings page. The file stays readable if you’d rather edit it.
History and logs%LOCALAPPDATA%\AMA\
ScratchA folder you choose in Setup, under Advanced.
Your LibrariesWherever you point them: a local disk, a mapped drive or a network share.

Updates

AMA checks GitHub for a newer release and shows Update available with a link. It never updates itself. Download the new installer and run it over the top; your settings and History stay.

Uninstall

Use Add or remove programs. Uninstalling removes the app and keeps %LOCALAPPDATA%\AMA\, unless you tick Also remove settings and history. It never touches your Libraries.
